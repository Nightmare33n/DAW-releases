# DAW — Releases

Instaladores oficiales de **DAW**, una estación de trabajo de audio centrada en el piano (Windows 10/11, x64).

## Instalar

1. Descarga `DAW-Setup-<versión>.exe` de la [última release](https://github.com/Nightmare33n/DAW-releases/releases/latest).
2. Ejecútalo. Se instala para tu usuario, sin permisos de administrador.

Requiere el runtime **Microsoft Edge WebView2** (incluido en Windows 11 y en la mayoría de Windows 10).

## Actualizaciones

DAW busca nuevas versiones aquí al iniciar, las descarga en segundo plano y las instala al cerrarse. También puedes ir a **Settings → Updates → Check for updates**. Cada instalador se verifica contra su archivo `.sha256` antes de ejecutarse.

Las novedades de cada versión están en las notas de su release.
